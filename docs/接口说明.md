# 接口契约

Python 参数名与 HTTP JSON 字段一致，路径相对于启动进程的当前目录。推荐传绝对路径。HTTP 为本机工具集成接口，不接收上传文件；使用本机已有文件路径。

| 方法与路径 | 必需字段 | 可选字段 |
|---|---|---|
| `GET /health` | 无 | 无 |
| `POST /v1/structure/export` | `project_root`, `book_id`, `output_dir` | 无 |
| `POST /v1/structure/build` | `source_graph`, `output_dir`, `book_id`, `book_title` | 无 |
| `POST /v1/concepts/prepare` | `project_root`, `output_dir` | `book_ids`, `config` |
| `POST /v1/concepts/build` | `corpus`, `output_dir` | `config`, `schema`, `prompts`, `allow_api`, `max_chunks` |
| `GET /v1/runs/status` | 查询参数 `output_dir` | 无 |
| `POST /v1/runs/export-process` | `output_dir`, `destination` | 无 |

构建成功返回运行状态和过程文件路径；准备成功返回完整 corpus。`200` 表示请求执行成功，必须继续查看构建 `state.phase`，不能把 `partial` 或 `complete_with_skips` 当作全量完成。

`400`：缺字段、格式错误、输入缺失或来源核验失败；`403`：浏览器 Origin 请求；`404`：未知路径；`409`：导出目录已存在或另一个构建持有运行锁；`500`：构建异常。异常会保留类型和运行状态，底层已有缓存不清除。失败后同一输入可以继续运行。

请求体必须是 JSON 对象，最大 1 MiB。`allow_api` 必须使用 JSON 布尔值 `true`。`runtime` 和 `projection` 为 Python 对象，只能通过 Python 接口注入。HTTP 构建同步执行，同一目录不能并发构建；可用另一个请求查看最新状态。

PowerShell 示例：

```powershell
$body = @{
  project_root = 'C:\path\to\project'
  book_id = 'book_bef9d155e6d8'
  output_dir = 'C:\path\to\new_structure_export'
} | ConvertTo-Json
Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:8765/v1/structure/export' -ContentType 'application/json; charset=utf-8' -Body ([System.Text.Encoding]::UTF8.GetBytes($body))
```

概念构建请求示例（需要真实模型环境变量）：

```json
{
  "corpus": "C:/work/prepared/corpus.json",
  "output_dir": "C:/work/run",
  "config": "C:/work/config/incremental.example.yaml",
  "allow_api": true,
  "max_chunks": 2
}
```

轮询：`GET http://127.0.0.1:8765/v1/runs/status?output_dir=C%3A%2Fwork%2Frun`。

Python 的 `build_concepts` 另支持 `runtime`、`projection`。注入的对象由调用者管理生命周期；内部创建的 `ModelRuntime` 在函数退出时关闭。默认只生成工作图，无数据库写入。投影对象应实现原引擎调用的 `sync_store(store)`；可使用随包保留的 `Neo4jProjection`。

## 状态判断

- `api_state.phase=running`：封装已启动，查看 `state` 获得原引擎进度。
- `api_state.phase=failed`：异常已向调用者传播，`last_error.json` 保存错误类型。
- `state.phase=partial`：按 `max_chunks` 完成本轮选定范围。
- `state.phase=complete_with_skips`：存在未成功片段或先验核查，不能宣称完整图谱。
- `state.phase=complete`：当前完整输入的自动阶段结束；`human_accepted` 仍为 false。

`inspect_run` 不创建运行目录。过程导出目录必须尚不存在且位于原运行目录之外。运行中导出可读取已落盘内容；需要一致的最终审计材料时应等待构建结束再导出。
